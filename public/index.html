声を聞きながら、
いっしょに海へ。

ことばの意味がまだわからなくても、読み手の声や、絵をいっしょに楽しむ時間に。好きなページだけでも、途中でおしまいでも大丈夫。

この絵本は自動で進まず、音も鳴りません。赤ちゃんの様子に合わせて、短い時間でゆっくりどうぞ。

同じさかな、変わる呼び名。

ブリは成長すると呼び名が変わる「出世魚」です。ここでは「関東の よびかた」と「関西の よびかた」を切り替えて楽しめます。関東はモジャコ → ワカシ → イナダ → ワラサ → ブリ、関西はモジャコ → ツバス → ハマチ → メジロ → ブリという代表的な呼び名を紹介しています。地域や大きさの区切りによって呼び名には違いがあり、各ページは厳密な同じ体長の対応ではありません。

絵は親しみやすく描いたイメージです。実際の大きさの比率とは異なります。
